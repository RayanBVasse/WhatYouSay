What this is

All processing is performed by scripts and language models. There is no human review, moderation, or manual intervention at any stage.

How data is handled

This is a fully automated, research-grade text analysis system. Uploaded files are processed temporarily on secure cloud infrastructure. Raw uploads and generated result files are stored in private storage only for processing. All uploaded content, generated outputs, and associated run records are deleted automatically within 24 hours, or immediately when you use Delete & Exit.

Legal and responsible use

This tool anonymises and analyses all messages in the uploaded file. If you upload a group conversation, you confirm that all participants have been informed and consent to this analysis. You also confirm that the uploaded conversation does not contain messages from individuals under 18, or that appropriate parental consent has been obtained. The platform operator does not verify consent and is not liable for unauthorized uploads.

Transparency

The analysis pipeline is implemented in open-source scripts. The codebase is available on GitHub for inspection by technically trained users. Outputs reflect model behavior and statistical patterning - not human judgment.

What this is not

This tool does not provide advice, diagnosis, or evaluation of individuals. It reports descriptive patterns in text and interaction structure only.
